# HERO
**Micro-label:** CERTIFICATION & THE MODEL REGISTRY
**Headline:** A public ledger of every model we have judged — and how.

# SECTION — CERTIFICATE CLASSES

- **C1 — Certified.** Meets its tier's full bar for general market offering.
- **C2 — Certified, Conditional.** Authorized with binding conditions
  (deployment scope, monitoring, mitigations) listed on the certificate face.
- **C3 — Provisional.** Time-boxed authorization for staged rollout while
  designated follow-up evidence accrues.
- **X — Declined / Revoked.** Public record with reasons class (capability
  misstatement, failed track, incident).

# SECTION — THE REGISTRY

Open, machine-readable (JSON + signed attestations). Each entry: model ID,
developer, version lineage, risk tier, certificate class and history,
conditions, incident log, harness versions, re-evaluation due date.
Search + filter UI (puijs Table): by tier, class, developer, status.

# SECTION — LIFECYCLE RULES

- Certificates bind to a model version; a major version or measured
  capability jump voids inheritance and triggers re-evaluation.
- Any party may file an incident under STD-400; triage within 72h.
- Suspension is immediate on confirmed critical incident; revocation follows
  Assembly-reviewed process. All actions are published within 24h.

# SECTION — MARKS

Usage rules for the "UAIA CERTIFIED · C1" mark: exact badge geometry, class
always shown, link-back to registry entry required. Misuse of the mark is
grounds for revocation.
