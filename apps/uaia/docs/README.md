# UAIA — apps/uaia

Website of the Unified Artificial Intelligence Agency (uaiagency.org),
built on `@phiace/puijs` like phlick/chanel. 16 pages; content lives in
`docs/` (one md per page) — approved content is the single source of truth
for the React pages.

- Brand: `uaia` theme in puijs `BRAND_THEMES` (signal cyan #22d3ee → indigo
  #818cf8 on near-black), glass style, portal archetype.
- Logo: original crescent-knot aperture mark + squarish-oval UAIA wordmark
  (SVG, in `src/components/brand/`).
- See `../../apps/README.md` for the workspace app conventions.
