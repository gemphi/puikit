# HERO
**Micro-label:** UAIA-STD SERIES
**Headline:** Standards you can diff.

**Intro:** Every UAIA standard is versioned, public, and published as both
prose and machine-readable schema. Comment periods are open to anyone.

# SECTION — THE CATALOG (table UI)

- **STD-100 · Model Disclosure.** What a Model Notification must contain:
  compute, data lineage classes, capability claims, eval hooks. v1.0
- **STD-110 · Versioning & Lineage.** What counts as a "new model"; capability
  -jump triggers for re-evaluation. v1.0
- **STD-200 · Evaluation Reproducibility.** Harness pinning, tolerance bands,
  contamination screening, third-party re-run accreditation. v1.0
- **STD-210 · Red-Team Practice.** Expert-hour floors per tier, domain
  coverage, disclosure handling. v0.9 draft
- **STD-300 · Deployment Conditions.** Condition taxonomy for C2 certificates:
  scope limits, agentic ceilings, human-oversight requirements. v1.0
- **STD-310 · Provenance & Watermarking.** Output provenance signals and
  verification APIs. v0.9 draft
- **STD-400 · Incident Reporting.** Severity ladder SEV-0…SEV-4, 72h triage,
  public postmortems for SEV-0/1. v1.0
- **STD-410 · Monitoring Telemetry.** Minimum deployment telemetry and
  privacy-preserving aggregation. v0.8 draft
- **STD-500 · Registry Interchange.** JSON schema + signature format for
  registry mirrors and national regulators. v1.0

# SECTION — PROCESS

Draft → 60-day public comment → Directorate revision → Board ratification →
Assembly review → Published with changelog. All comments are public.
